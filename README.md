# PL Motos

Site institucional para a oficina e serviços de motos da PL Motos, localizado em Itapema/SC.

## Visão geral

Este projeto é uma landing page moderna e responsiva para divulgar a oficina, com:
- apresentação da marca
- serviços oferecidos
- diferenciais da empresa
- depoimentos
- área de contato/WhatsApp
- layout otimizado para mobile e desktop

## Como abrir localmente

1. Clone o repositório.
2. Abra o arquivo `index.html` no navegador.
3. Para visualizar em um servidor local, você pode usar uma extensão como Live Server ou executar um pequeno servidor em Python.

Exemplo:

```bash
python -m http.server 8000
```

Depois acesse:

```text
http://localhost:8000
```

## Observação importante

Os dados de WhatsApp e outros contatos podem ser ajustados diretamente no arquivo `index.html`.
